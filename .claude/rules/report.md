# Report and worklog
- The report is written while building, not after.
- For every closed issue, write searchashouses/report/worklog/<issue#>-<slug>.md with: Reason, Changes, Challenges, How it works, Outcome (commands, metrics, links), Conclusion, Appendix: screenshots (searchashouses/report/screenshots/<issue#>-<name>.png).
- searchashouses/report/ is git-ignored. Screenshots must not show keys, secrets or subscription IDs.
- Plain, simple English. The final report is built from these entries.
